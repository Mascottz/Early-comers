# Attendance videos

Remotion projects for **Attendance by ProofsTech**:

| Composition | What it is | Output |
| --- | --- | --- |
| `InstallVideo` | 3D install guide for iPhone and Android, no narration | `out/attendance-install.mp4` |
| `AdVideo` | Narrated brand ad / product walkthrough, ~72 s | `out/attendance-ad.mp4` |


- 1920×1080, 30 fps, ~35 s, H.264 with no audio track
- Composition id `InstallVideo`
- Output `out/attendance-install.mp4`

## Commands

```bash
npm install
npm run studio      # Remotion Studio preview
npm run typecheck
npm run render      # install guide -> out/attendance-install.mp4
npm run render:ad   # ad -> out/attendance-ad.mp4
npm run still:ad    # single poster frame -> out/ad-poster.png
```

Remotion downloads its own `chrome-headless-shell` on first render (`npx remotion browser ensure`). If Chrome is already on the machine, point Remotion at it:

```bash
REMOTION_BROWSER_EXECUTABLE=/path/to/chrome npm run still
```

## The ad (`AdVideo`)

Scenes, in order: hook → today → office pass → scan → lateness → daily wall → team → install/close.

- **Visuals** use the real app screenshots in `public/screens/` (today, daily wall, team, office QR), framed in a browser card with a slow camera pan, plus typographic scenes for the hook, the 09:30 / ₦2,000 rule, and the closing call to action.
- **Narration** is pre-rendered speech in `public/audio/ad-01…08.mp3`, one clip per scene. Scene lengths in `src/ad/timeline.ts` are derived from those clips (clip length + a short breath), so re-recording a line only needs a new duration in that table.
- **Music** is a synthesised pad, `public/audio/music-bed.mp3`, generated by `tools/make_music.py` (`numpy` only). Remotion fades it in and out and keeps it low under the voice.

## Structure

| File | Purpose |
| --- | --- |
| `src/Root.tsx` | registers the `InstallVideo` composition |
| `src/InstallVideo.tsx` | scene order and transitions |
| `src/timeline.ts` | scene durations, size, fps |
| `src/scenes/IntroScene.tsx` | title card |
| `src/scenes/IphoneScene.tsx` | Safari share sheet → Add to Home Screen |
| `src/scenes/AndroidScene.tsx` | Chrome ⋮ menu → Add to Home screen |
| `src/scenes/OutroScene.tsx` | recap + `earlycomers.vercel.app` |
| `src/ad/AdVideo.tsx` | ad timeline, narration and music tracks |
| `src/ad/scenes/*` | ad scenes (hook, feature screenshots, scan, lateness, close) |
| `src/ad/components/*` | browser card, scene header, background, logo lockup |
| `src/Phone.tsx` | CSS-3D phone frame, status bar, icons |
| `src/screens/*` | in-phone mock UI (site page, share sheet, home screen) |
| `src/components/*` | instruction panel, callouts, scene background |
| `src/theme.ts` | brand colours and font stacks |

## Fonts

`public/fonts/` holds Bricolage Grotesque (600/700) and DM Sans (400/500) as `.woff2`, copied from the PWA's `public/fonts/`. Both are licensed under the SIL Open Font License; the licence files are vendored next to them and must stay there when the fonts are redistributed (for example inside the rendered MP4).

## CI

Two workflows run on pushes to `main` touching `video/` and via **Run workflow**:

- `.github/workflows/install-video.yml` → `attendance-install-video` artifact and the `install-video-latest` release.
- `.github/workflows/ad-video.yml` → `attendance-ad-video` artifact and the `ad-video-latest` release.

Both install dependencies with `npm ci`, typecheck, ensure headless Chrome, render, upload the MP4, and refresh their release.
